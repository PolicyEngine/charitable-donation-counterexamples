# Charitable donation counterexamples

Reproducible PolicyEngine household analysis of whether a charitable gift can ever save at least its cost in taxes and benefits. Work in progress, started November 12, 2026.

Claim being tested: https://x.com/Sharkyl/status/2120742568900329482

All households are hypothetical. This analysis will distinguish ordinary cash deductions, donation tax credits, and threshold interactions. No population microdata is required.
